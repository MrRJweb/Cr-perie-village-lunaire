# Nails, Lashes & Esthetics — Beauty Studio Website

A modern, single-page website for a beauty studio, built with plain HTML, CSS and JavaScript — no frameworks, no build step.

**Tagline:** *Beauty in every detail*

## Features

- Soft, feminine design — blush pink, cream and rose-gold palette with elegant serif headings and airy spacing
- Sticky navbar with mobile hamburger menu and scroll-spy link highlighting
- Full-screen hero with soft-toned backdrop, light overlay and call-to-action buttons
- Services card grid (manicure, pedicure, gel & acrylic, lash extensions, lash lift, brows, facials)
- Instagram-style gallery of 8 placeholder photos with hover effects
- Two-column pricing menu grouped by category
- Front-end-only booking form (name, phone, service, date, time) with validation and a success message
- Client testimonials with star ratings
- Opening hours, contact details and a stylised map placeholder
- Smooth scrolling, gentle fade-in animations, fully responsive, reduced-motion friendly

## Viewing

Open `index.html` in any browser — no server required.
